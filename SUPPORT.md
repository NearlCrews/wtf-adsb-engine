# Support

Use this repository's GitHub Issues for questions, bug reports, and feature
requests. Search existing issues first. Select the matching issue template and
include the engine version, Python version, operating system, and a minimal
synthetic reproduction.

Start with [configuration](docs/configuration.md),
[operating and troubleshooting](docs/operations.md), or the
[documentation index](docs/README.md). A downstream publisher's formatting,
publication policy, and deployment belong to that application's support channel.

Keep credentials, journals, flight archives, private receiver URLs, and receiver
locations out of public reports. Report vulnerabilities and accidental data
disclosures through [SECURITY.md](SECURITY.md).

Support is provided as maintainer time permits, without a guaranteed response
time. This project does not provide an aircraft identification service or verify
who is aboard an aircraft.
